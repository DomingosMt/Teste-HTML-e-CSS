# Teste-HTML-e-CSS

## Descrição

Este é um projeto de teste para praticar e demonstrar o uso básico de HTML e CSS. O objetivo é criar uma página web simples com estilos aplicados.

## Estrutura do Projeto

- `index.html`: Arquivo principal da página web, contendo a estrutura HTML.
- `style.css`: Arquivo de estilos CSS para personalizar a aparência da página.
- `imgs/`: Pasta destinada a armazenar imagens utilizadas no projeto.
- `README.md`: Este arquivo de documentação.

## Uso de Bibliotecas

Este projeto utiliza as seguintes bibliotecas externas:

- **Google Fonts**: Para a fonte Poppins, importada via CSS para estilizar o texto da página.
- **Phosphor Icons**: Biblioteca de ícones vetoriais, carregada via CDN para adicionar ícones como carrinho de compras e setas no menu de navegação.
